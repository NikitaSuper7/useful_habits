Это курсовой проект, в котором мы разрабатываем бэк-енд для приложения полезных привычек с интеграцией с телеграм.
Проект позволяет пользователю не забывать про свои привычки и выполнять их.
Что положительно влияет на его здоровье.

Используемый стек:
python
django
djangorestframework
pillow
psycopg2-binary
requests
celery
redis
django-celery-beat
worker
coreapi
pyyaml
